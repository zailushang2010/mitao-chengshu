# CHANGE: 侧栏收藏

## DEFINE

### 问题
侧栏已有「收藏」入口，但仅 toast「即将推出」。用户无法标记/回看喜爱片源。

### 用户与场景
单机用户在随机预览时想「先收着」，之后从收藏里挑、随机抽、直接开播。

### 范围内
- 按模式持久化收藏：`favorites.json` / `favorites_images.json`（与 exe 同数据目录）
- 预览片单：右键「收藏 / 取消收藏」；多选条「收藏」
- 卡片已收藏有轻量星标提示
- 侧栏「收藏」进入收藏台：展示**当前模式**收藏（电影/图片切换同步）
- 收藏台：多选播放 / 取消收藏；「随机预览」只从收藏抽；空态引导
- 拉黑时自动移出收藏（避免矛盾）
- 收藏**不**改变片库随机池（仍从全库抽）

### 范围外
- 云同步、跨设备、文件夹收藏、评分排序
- 收藏专用媒体模式（不新增 MediaMode）
- 设置页完整收藏管理（收藏台可取消即可）

### 验收
- [ ] 收藏后重启仍在
- [ ] 电影/图片收藏互不串
- [ ] 侧栏进入收藏台可见列表；无条目时空态
- [ ] 多选可播放、取消收藏
- [ ] 收藏台随机预览仅来自收藏
- [ ] 拉黑条目不再出现在收藏
- [ ] `cargo test` / `cargo build --release` 通过

## PLAN

### 方案
复用黑名单的路径列表持久化模式；UI 用 `StageView::{Browse, Favorites}` 切换主区，不碰 MediaMode。

### 任务
1. `src/favorites.rs` + 单测
2. `session`：加载/保存、toggle、批量收藏、拉黑时剔除、从收藏 roll/start
3. `widgets`：选中栏「收藏」、卡片 `favorited`
4. `app`：侧栏激活态、收藏台主区、预览右键
5. 更新 DEFINE/PLAN 基线摘要

### 风险
- 收藏路径已删：列表过滤不存在文件，取消收藏可清幽灵项
- 与播放中状态：仅 Idle 可改片单；收藏标记可在 Idle 预览操作

### VERIFY
- `cargo test`
- `cargo build --release`
- 手测：收藏 → 重启 → 收藏台 → 播放 → 取消 → 拉黑联动
