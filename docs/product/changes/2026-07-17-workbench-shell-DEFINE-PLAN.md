# CHANGE: 工作台壳层 + 播放时置顶修复 + 图标

## DEFINE

### 问题

1. 竖版杂志布局在横屏下预览与操作抢空间；用户要 **工作台**：左侧可收操作栏、主区给预览。
2. 「播放时置顶」用裸 `SetWindowPos`，与 winit 的 `ALWAYS_ON_TOP` 不同步，实际无效。
3. 产品图标更新需重新嵌入 exe。

### 范围内

- 横版窗口；顶栏工具条（侧栏开关、模式、本轮数量 ±、状态、片库、工具图标）
- 左侧可折叠操作栏（避开最近、主/次按钮、片单；无「操作/收起」冗余标题）
- 右侧主舞台预览网格铺满
- 片单行：单行片名 + 剔除/拉黑（或播放中置前/独播/关闭）；悬停仅一个无后缀全名
- 播放时置顶：`ViewportCommand::WindowLevel` + Win32 同步 + raise 不误清 TOPMOST
- 启动居中；新 `icon.ico` 嵌入

### 范围外

- 多显示器选屏（→ P2-2）
- 操作栏宽度拖拽、布局持久化到 config
- 重新设计设置面板内部

### 验收

- [ ] 默认横版约 1024×640；侧栏可关，预览几乎占满
- [ ] 本轮数量在顶栏可调；侧栏无重复数量行
- [ ] 预览后片单单行；悬停一个名字
- [ ] 电影 Playing + 置顶开：面板压在 PotPlayer 上；关置顶后可被盖住；最小化可正常落下
- [ ] `cargo test` / `cargo build --release` 通过；exe 为新图标
