# 蜜桃成熟 · 发版 VERIFY 手测清单（基线）

> 与 `DEFINE.md` §7 对齐。  
> **用法**：发版前复制到 `VERIFY-log.md` 新条目，或运行：  
> `pwsh -File scripts/new-verify-entry.ps1 [-Title "短说明"]`  
> 再跑：`pwsh -File scripts/verify.ps1`

勾选约定：`[x]` 通过 · `[ ]` 未测 · `[!]` 失败（附说明）· `[-]` 本环境不适用

---

## A. 命令（必须）

- [ ] `cargo test`（记录：passed / failed / ignored）
- [ ] `cargo build --release`（记录：成功 / exe 被占用等）
- [ ] （可选）`pwsh -File scripts/pack.ps1` → `dist/` zip

---

## B. 配置与索引

- [ ] 添加/移除电影目录，重启后仍在
- [ ] 添加/移除图片目录，与电影独立
- [ ] 坏 `config.json` 不发明路径（可备份）
- [ ] 索引中显示「已发现 N」；完成后数量可信
- [ ] 二次启动明显走缓存（大库）；「重新扫描」强制全量
- [ ] 索引中可「取消索引」

---

## C. 电影模式

- [ ] 随机预览数量在设定范围内
- [ ] 避开最近时明显少撞车
- [ ] 剔除仅本轮；拉黑后不再抽到；设置可移出黑名单
- [ ] 开启后 N 窗入网格，**无明显旧尺寸跳出**
- [ ] 「重新平铺」可收回乱局
- [ ] 关闭本轮仅结束本工具启动的实例
- [ ] 播放中切图片：PotPlayer 仍在；可关掉后台电影
- [ ] 设置「平铺工作区」选副屏时，开播落副屏（无副屏则 `[-]`）

---

## D. 图片模式

- [ ] 数量与电影独立
- [ ] 幻灯可开、暂停/切图、Esc 结束
- [ ] 平铺墙可开、点击放大、Esc 结束

---

## E. 单实例与壳层

- [ ] 已运行时再开 exe：不出现第二主进程
- [ ] 托盘/最小化后再开 exe：原窗到前台
- [ ] 侧栏可隐藏/显示；隐藏后预览接近全宽
- [ ] 侧栏开合重启后保持（config）
- [ ] 本轮数量仅在顶栏
- [ ] 播放时置顶开：面板在 PotPlayer 之上；关则否；最小化正常
