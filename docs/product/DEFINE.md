# 蜜桃成熟 · DEFINE（产品定义）

> 版本基线：0.6.x（以 `Cargo.toml` 为准；当前 0.6.2）  
> 最后更新：2026-07-17  
> 生命周期：`docs/process/lifecycle.md`

---

## 1. 问题

本地视频/图片过多时，选择困难：需要一种 **随机抽取 + 预览确认 + 一键多开观看** 的轻量工具，而不是在资源管理器里反复点开。

---

## 2. 用户与场景

| 角色 | 场景 |
|------|------|
| 单机 Windows 用户 | 本地大片库/图库，已安装或可指定 PotPlayer |
| 使用节奏 | 偶尔一轮随机，不是剪辑工作站 |

---

## 3. 产品定位

- **名称**：蜜桃成熟  
- **形态**：单 exe 绿色运行，纸感杂志风 UI（egui）  
- **核心循环**：索引 → 随机预览 →（可剔除）→ 确认开启 → 观看/结束 → 再来一批  

---

## 4. 范围内（当前应具备）

### 4.1 电影模式

- 多目录递归索引（可配置扩展名）
- 本轮数量独立配置（min/max/default）
- 随机预览、**换一部**（只换该项）、**多选批量换/剔除/收藏/拉黑**（右侧预览格点击选中 / 左侧勾选，同一套选中状态）、剔除（本轮减员）、**拉黑（永久不再抽到）**、再来一批（全换、不自动开播）
- 黑名单按模式持久化（`blacklist.json` / `blacklist_images.json`），设置可移出
- **收藏**按类型分存（`favorites.json` / `favorites_images.json`）：预览右键/多选收藏；侧栏「收藏」为独立台，内含 **电影 / 图片** 两架切换（带数量）；多选播放/取消、从当前架随机预览；拉黑自动移出；不改变全库随机池
- 多开 PotPlayer（`/new`），按工作区网格平铺（**完整体验**）
- **无 PotPlayer 时降级**：仍可随机预览/换片/拉黑；「开启」用**系统默认程序**打开本轮文件（无网格平铺、无单部控制）；设置可指定路径
- **几何约束**（Pot 路径）：启动后先隐藏再入格；播放中持续纠正窗口几何
- 单部：置前、独播、关闭；本轮关闭；可选播放时面板置顶（仅 Pot 多开）
- 历史 `history.json` + 避开最近
- 与图片并存：切图片不杀 PotPlayer；可后台关掉或切回关闭本轮
- **平铺工作区可选显示器**（设置 → 平铺工作区；默认系统主工作区）

### 4.2 图片模式

- 独立图库路径与数量配置
- 预览后：幻灯片 / 平铺墙
- 历史 `history_images.json`
- 幻灯：间隔、暂停、左右切、Esc；墙：点击放大

### 4.3 通用

- 设置：路径列表、数量范围、图片开启方式、PotPlayer 路径、托盘/退出行为
- 后台索引 + 显示「已发现 N」
- 播放/后台 PID 探活
- Toast 叠层、按压反馈等手感规范（见 design docs）
- 打包：`scripts/pack.ps1` → `dist/`
- **单实例**：命名 Mutex；二次启动唤醒已有窗口（含托盘隐藏），不并行第二进程
- **工作台壳层**（对齐 1.png 原型）：
  - 左侧图标导航：电影 / 图片 / **收藏** / 设置
  - 顶栏：模式标题、数量步进、状态胶囊、片库摘要、扫描/置顶/托盘
  - 操作条：开启/随机预览 · 再来一批 · 避开最近 · 片名搜索（空格多词 AND；空闲搜片库可加入本轮；收藏/播放中筛当前列表）· 卡片列数
  - 卡片式预览网格（封面 + 标题）；多选批量换/剔除/**收藏**/拉黑；已收藏星标
  - 窗口大小与位置写入 `config.json`（可插拔显示器失效时回退）
  - 收藏台：独立货架（电影/图片 chip + 数量）；多选播放/取消；从当前架随机预览
  - 底栏：库总量 · 当前显示/筛选 · 刷新
  - 播放中：以卡片为主（点选/右键 **换片 · 移出**；电影另有独播/置前）；可选「清单」展开完整片名列表
  - 电影「播放时置顶」经 winit `WindowLevel` + Win32 同步

---

## 5. 范围外（非目标）

- 云同步、账号、推荐算法
- 内置完整视频解码播放；任意第三方播放器的网格多开/几何控制
- 向 PotPlayer 可靠注入音量（不做无效音量 UI）
- 跨平台（当前仅 Windows）
- 多用户权限/企业 MDM

---

## 6. 约束

| 类 | 内容 |
|----|------|
| 平台 | Windows，UTF-8 路径 |
| 播放 | 电影优先 = PotPlayer 多实例；无 Pot 时系统默认打开（功能降级） |
| 配置 | 与 exe 同目录；不写死盘符；删路径不得被 legacy 复活 |
| 体验 | 高频操作（模式切换、数量 ±）不加装饰动画 |
| 流程 | 遵守 DEFINE→PLAN→BUILD→VERIFY→REVIEW |

## 7. 验收标准（基线）

### 配置与索引

- [ ] 可添加/移除电影、图片目录，重启后保留
- [ ] 坏 `config.json` 不发明路径；可备份
- [ ] 索引中显示已发现数量；完成后数量可信
- [ ] 二次启动可走磁盘索引缓存（明显更快）；「重新扫描」强制全量
- [ ] 索引中可「取消索引」

### 电影

- [ ] 随机预览数量在设定范围内；避开最近时明显少撞车
- [ ] 剔除仅本轮；拉黑后不再抽到；设置可移出黑名单
- [ ] 收藏：预览可收藏；侧栏可见；重启仍在；电影/图片分存；拉黑移出收藏
- [ ] 有 PotPlayer：开启后 N 个实例进入工作区网格，**无明显窗口保持旧尺寸跳出**
- [ ] 无 PotPlayer：仍可预览；开启用系统默认打开并提示降级；设置可指定路径
- [ ] 「重新平铺」可将乱局收回（Pot 路径）
- [ ] 关闭本轮仅结束本工具启动的实例（Pot 路径）
- [ ] 播放中切图片：PotPlayer 仍在；可「关掉电影」或切回「关闭本轮」
- [ ] 设置可选平铺显示器；双屏时副屏开播落点在副屏工作区

### 图片

- [ ] 幻灯/墙可开可 Esc 结束
- [ ] 数量配置与电影独立

### 单实例

- [ ] 已运行时再启动 exe：不出现第二个主进程
- [ ] 窗口在托盘/最小化时再启动：原窗口被带到前台

### 工作台与置顶

- [ ] 无左侧操作栏；预览区全宽；主操作在舞台顶条
- [ ] 本轮数量仅在顶栏调节
- [ ] 播放中置顶开时控制面板压在 PotPlayer 之上；关则不强制；最小化可落到任务栏

### 工程

- [ ] `cargo test` 通过
- [ ] `cargo build --release` 成功

## 8. 已知限制

| 限制 | 说明 |
|------|------|
| PotPlayer 行为 | 不同版本/皮肤仍可能抢焦点；几何守护会纠正，极端皮肤需手测 |
| 超大库首次索引 | 首次全量扫；之后按**目录树签名**缓存；嵌套增删自动/手动智能刷新（只重扫变化目录，扫完前保留旧名单）；Shift+重新扫描才全量重扫 |
| 图片墙内存 | 大图原图像素墙可能吃内存（缩略图化在 PLAN） |
| 音量 | 不由本工具控制 |
| 平铺工作区 | 可选手动选屏；显示器热插拔后 index 可能漂移，不可用则回退 |
| 壳层布局 | 侧栏开合、卡片列数、窗口大小/位置会记忆；最大化/全屏态不记；位置失效时回退居中 |

---

## 9. 成功指标（产品感）

- 从打开到「在看」路径短：预览确认后一键开播
- 多开时网格可信，不依赖用户手动拖窗口
- 电影/图片切换不卡顿、不误杀用户手动开的播放器
