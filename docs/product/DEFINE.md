# 蜜桃成熟 · DEFINE（产品定义）

> 版本基线：0.6.x（以 `Cargo.toml` 为准；当前 0.6.2）  
> 最后更新：2026-07-17  
> 生命周期：`docs/process/lifecycle.md`

---

## 1. 问题

本地视频/图片过多时，选择困难：需要一种 **随机抽取 + 预览确认 + 一键多开观看** 的轻量工具，而不是在资源管理器里反复点开。

---

## 2. 用户与场景

| 角色 | 场景 |
|------|------|
| 单机 Windows 用户 | 本地大片库/图库，已安装或可指定 PotPlayer |
| 使用节奏 | 偶尔一轮随机，不是剪辑工作站 |

---

## 3. 产品定位

- **名称**：蜜桃成熟  
- **形态**：单 exe 绿色运行，纸感杂志风 UI（egui）  
- **核心循环**：索引 → 随机预览 →（可剔除）→ 确认开启 → 观看/结束 → 再来一批  

---

## 4. 范围内（当前应具备）

### 4.1 电影模式

- 多目录递归索引（可配置扩展名）
- 本轮数量独立配置（min/max/default）
- 随机预览、剔除、**拉黑（永久不再抽到）**、再来一批（不自动开播）
- 黑名单按模式持久化（`blacklist.json` / `blacklist_images.json`），设置可移出
- 多开 PotPlayer（`/new`），按工作区网格平铺
- **几何约束**：启动后先隐藏再入格；播放中持续纠正窗口几何（对抗「记忆位置/大小」）
- 单部：置前、独播、关闭；本轮关闭；可选播放时面板置顶
- 历史 `history.json` + 避开最近
- 与图片并存：切图片不杀 PotPlayer；可后台关掉或切回关闭本轮
- **平铺工作区可选显示器**（设置 → 平铺工作区；默认系统主工作区）

### 4.2 图片模式

- 独立图库路径与数量配置
- 预览后：幻灯片 / 平铺墙
- 历史 `history_images.json`
- 幻灯：间隔、暂停、左右切、Esc；墙：点击放大

### 4.3 通用

- 设置：路径列表、数量范围、图片开启方式、PotPlayer 路径、托盘/退出行为
- 后台索引 + 显示「已发现 N」
- 播放/后台 PID 探活
- Toast 叠层、按压反馈等手感规范（见 design docs）
- 打包：`scripts/pack.ps1` → `dist/`
- **单实例**：命名 Mutex；二次启动唤醒已有窗口（含托盘隐藏），不并行第二进程
- **工作台壳层**（横版）：
  - 顶栏：侧栏开关、电影/图片、本轮数量 ±、状态、片库摘要、设置/扫描/置顶/托盘
  - 左侧可折叠操作栏：避开最近、主按钮、片单（剔除/拉黑或播放中单部操作）
  - **操作栏开合写入 config**，下次启动恢复
  - 右侧主舞台：本轮预览网格铺满可用区
  - 电影「播放时置顶」经 winit `WindowLevel` + Win32 同步，最小化时释放

---

## 5. 范围外（非目标）

- 云同步、账号、推荐算法
- 内置完整视频解码播放（电影依赖 PotPlayer）
- 向 PotPlayer 可靠注入音量（不做无效音量 UI）
- 跨平台（当前仅 Windows）
- 多用户权限/企业 MDM

---

## 6. 约束

| 类 | 内容 |
|----|------|
| 平台 | Windows，UTF-8 路径 |
| 播放 | 电影 = 外部 PotPlayer 多实例 |
| 配置 | 与 exe 同目录；不写死盘符；删路径不得被 legacy 复活 |
| 体验 | 高频操作（模式切换、数量 ±）不加装饰动画 |
| 流程 | 遵守 DEFINE→PLAN→BUILD→VERIFY→REVIEW |

---

## 7. 验收标准（基线）

### 配置与索引

- [ ] 可添加/移除电影、图片目录，重启后保留
- [ ] 坏 `config.json` 不发明路径；可备份
- [ ] 索引中显示已发现数量；完成后数量可信
- [ ] 二次启动可走磁盘索引缓存（明显更快）；「重新扫描」强制全量
- [ ] 索引中可「取消索引」

### 电影

- [ ] 随机预览数量在设定范围内；避开最近时明显少撞车
- [ ] 开启后 N 个实例进入工作区网格，**无明显窗口保持旧尺寸跳出**
- [ ] 「重新平铺」可将乱局收回
- [ ] 关闭本轮仅结束本工具启动的实例
- [ ] 播放中切图片：PotPlayer 仍在；可「关掉电影」或切回「关闭本轮」
- [ ] 设置可选平铺显示器；双屏时副屏开播落点在副屏工作区

### 图片

- [ ] 幻灯/墙可开可 Esc 结束
- [ ] 数量配置与电影独立

### 单实例

- [ ] 已运行时再启动 exe：不出现第二个主进程
- [ ] 窗口在托盘/最小化时再启动：原窗口被带到前台

### 工作台与置顶

- [ ] 侧栏可隐藏/显示；隐藏后预览区接近全宽
- [ ] 侧栏开合重启后保持
- [ ] 本轮数量仅在顶栏调节
- [ ] 播放中置顶开时控制面板压在 PotPlayer 之上；关则不强制；最小化可落到任务栏

### 工程

- [ ] `cargo test` 通过
- [ ] `cargo build --release` 成功

## 8. 已知限制

| 限制 | 说明 |
|------|------|
| PotPlayer 行为 | 不同版本/皮肤仍可能抢焦点；几何守护会纠正，极端皮肤需手测 |
| 超大库首次索引 | 首次仍全量扫；之后按根目录缓存（mtime 签名，深层改动需点重新扫描） |
| 图片墙内存 | 大图原图像素墙可能吃内存（缩略图化在 PLAN） |
| 音量 | 不由本工具控制 |
| 平铺工作区 | 可选手动选屏；显示器热插拔后 index 可能漂移，不可用则回退 |
| 壳层布局 | 侧栏开合已持久化；窗口大小/位置仍不记忆 |

---

## 9. 成功指标（产品感）

- 从打开到「在看」路径短：预览确认后一键开播
- 多开时网格可信，不依赖用户手动拖窗口
- 电影/图片切换不卡顿、不误杀用户手动开的播放器
